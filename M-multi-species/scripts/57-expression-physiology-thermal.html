1 Goal

55-56.1 showed that gene-body methylation is a stable colony trait, while expression and physiology change through time. This script asks which expression programmes track which physiological changes, and how both relate to the thermal history before each sampling.

  1. Thermal history at Manava and Mahana (the two sites with sequenced colonies) over the 7, 30 and 90 days before each sampling visit.
  2. Expression modules per species (signed WGCNA on VST expression).
  3. Modules vs physiology with repeated-measures mixed models, splitting each module into a between-colony and a within-colony part.
  4. Thermal history vs modules and physiology across the 8 site-by-timepoint units.
  5. Cross-species concordance: do one-to-one orthologs relate to the same physiological trait in the same direction in all three species?

1.1 Caveats that apply throughout

  • Only 8 environmental states (2 sites x 4 timepoints). Thermal metrics cannot be separated from anything else that changes with season (light, nutrients, reproduction). Section 4 identifies which seasonal axis a module follows, consistent with temperature; it does not establish that temperature causes it.
  • Sampling dates are approximate. The sample sheets record month only. Each window ends on the last logger reading before the field-visit gap in the temperature record (visit_end below). The 90-day TP1 window is partly before logger deployment (61 of 90 days covered).
  • Within-colony associations include shared seasonal change. The “net of time” models remove site-by-timepoint means and test only colony-specific co-variation.

2 Thermal history

Daily summaries use local time (UTC-10). For each site, timepoint and window:

  • mean: mean of daily mean temperature
  • max: highest single reading
  • range: mean daily range (max - min)
  • heat: accumulated degree-days above 29 C, scaled to the full window length when coverage is incomplete
  • slope: trend in daily mean (C per week)
temp <- fread(temp_url)

3 Expression modules

Signed WGCNA per species on VST expression of the 10^{4} most variable genes (among genes with at least 10 reads in a quarter of samples). The soft-threshold power is the smallest giving a signed scale-free fit of at least 0.8, or 14 (the WGCNA FAQ value for 30-40 samples) if none does. Networks are cached in the output folder.

canon <- function(x) {
  hit <- grepl("(ACR|POR|POC)-[0-9]+[-_]TP[1-4]", x)
  out <- rep(NA_character_, length(x))
  out[hit] <- sub("_", "-", regmatches(x, regexpr("(ACR|POR|POC)-[0-9]+[-_]TP[1-4]", x)))
  out
}
as_matrix <- function(dt) {
  keep <- names(dt)[-1]; s <- canon(keep)
  keep <- keep[!is.na(s)]; s <- s[!is.na(s)]
  m <- as.matrix(dt[, ..keep]); storage.mode(m) <- "double"
  if (anyDuplicated(s)) m <- t(rowsum(t(m), s)) else colnames(m) <- s
  rownames(m) <- dt[[1]]
  m[, sort(colnames(m)), drop = FALSE]
}
vst_counts <- function(m, min_count = 10) {
  m <- round(m)
  m <- m[rowSums(m >= min_count) >= ceiling(ncol(m) / 4), , drop = FALSE]
  dds <- DESeqDataSetFromMatrix(m, data.frame(row.names = colnames(m)), ~ 1)
  dds <- estimateSizeFactors(dds, type = "poscounts")
  assay(varianceStabilizingTransformation(dds, blind = TRUE))
}

4 Modules vs physiology

Physiology traits measured on the same fragments as the RNA. Strictly positive traits are log10 transformed; all traits and eigengenes are standardised within species.

For each module and trait the eigengene is split into the colony mean (between) and the deviation from it (within):

  • model A: trait ~ within + between + (1 | colony)
  • model B: trait ~ within + between + site:timepoint + (1 | colony), so the within effect is net of change shared by all colonies

p-values are Satterthwaite (lmerTest); FDR is within species and model.

fit_mt <- function(d, net_time) {
  f <- if (net_time) y ~ x_w + x_b + st + (1 | colony) else y ~ x_w + x_b + (1 | colony)
  m <- suppressMessages(lmer(f, d, REML = TRUE))
  co <- coef(summary(m))
  data.table(beta_within = co["x_w", "Estimate"], p_within = co["x_w", "Pr(>|t|)"],
             beta_between = co["x_b", "Estimate"], p_between = co["x_b", "Pr(>|t|)"])

5 Thermal history vs modules and physiology

Each module eigengene and trait is centred on its colony mean, then averaged within the 8 site-by-timepoint units and correlated with every thermal metric. With 8 points, p-values have 6 degrees of freedom and the metrics are strongly collinear, so this ranks which window and metric fits best rather than testing them against each other.

unit_means <- function(v, md) {
  w <- v - ave(v, md$colony, FUN = function(x) mean(x, na.rm = TRUE))
  data.table(st = md$st, w = w)[!is.na(w), .(value = mean(w)), by = st]
}
assoc <- rbindlist(lapply(names(ME), function(s) {
  smp <- intersect(rownames(ME[[s]]), phys$sample)
  md <- meta[smp]
  vars <- c(setNames(lapply(colnames(ME[[s]]), function(mod) ME[[s]][smp, mod]),
                     paste("module", colnames(ME[[s]]))),
            setNames(lapply(names(traits), function(tr) phys[smp][[tr]]),
                     paste("trait", traits)))
  rbindlist(lapply(names(vars), function(v) {
    u <- merge(unit_means(vars[[v]], md), thermal, by = "st")
    rbindlist(lapply(metric_cols, function(mc) {
      r <- stats::cor(u$value, u[[mc]])
      data.table(species = s, variable = v, metric = mc, units = nrow(u), r = r,
                 p = 2 * pt(-abs(r * sqrt((nrow(u) - 2) / (1 - r^2))), nrow(u) - 2))
    }))
  }))
}))
fwrite(assoc, file.path(out_dir, "thermal-associations.csv"))

best <- assoc[, .SD[which.max(abs(r))], by = .(species, variable)]

The p-value of the best of 15 collinear metrics is optimistic. perm_p corrects for that choice: the 8 unit values of a variable are shuffled among units 5,000 times, and each time the best |r| over all metrics is recorded. perm_p is the share of shuffles whose best |r| matches or beats the observed one, so it accounts for both picking the best metric and their collinearity.

thermal_mat <- as.matrix(thermal[, ..metric_cols]); rownames(thermal_mat) <- thermal$st
perm_orders <- replicate(5000, sample.int(nrow(thermal_mat)))
best_perm <- rbindlist(lapply(names(ME), function(s) {
  smp <- intersect(rownames(ME[[s]]), phys$sample)
  md <- meta[smp]
  vars <- c(setNames(lapply(colnames(ME[[s]]), function(mod) ME[[s]][smp, mod]),
                     paste("module", colnames(ME[[s]]))),
            setNames(lapply(names(traits), function(tr) phys[smp][[tr]]),
                     paste("trait", traits)))
  rbindlist(lapply(names(vars), function(v) {
    u <- unit_means(vars[[v]], md)
    tm <- thermal_mat[u$st, , drop = FALSE]
    obs <- max(abs(stats::cor(u$value, tm)))
    null <- apply(perm_orders[seq_len(nrow(u)), , drop = FALSE], 2, function(o)
      if (nrow(u) == nrow(thermal_mat)) max(abs(stats::cor(u$value[o], tm))) else NA_real_)
    data.table(species = s, variable = v, perm_p = (1 + sum(null >= obs, na.rm = TRUE)) /
                 (1 + sum(!is.na(null))))
  }))
}))

6 Cross-species concordance through orthologs

For each one-to-one three-way ortholog and each trait, the within-colony correlation between gene expression and the trait is computed in each species. If the same genes track the same trait in the same direction across species, those correlations should agree across orthologs.

Concordance is the Spearman correlation of the per-ortholog values between two species. The null shuffles the trait among timepoints within colony in one species of the pair. As in section 3, the “within colony” version includes shared seasonal change, so concordance there can reflect a conserved seasonal programme; the “net of shared time” version cannot.

resid_rows <- function(Y, X) {
  q <- qr(X); Q <- qr.Q(q)[, seq_len(q$rank), drop = FALSE]
  Y - (Y %*% Q) %*% t(Q)
}
gene_trait_r <- function(s, tr, net_time, shuffle = FALSE) {
  smp <- intersect(colnames(expr[[s]]), phys$sample)
  y <- phys[smp][[tr]]; keep <- !is.na(y); smp <- smp[keep]; y <- y[keep]
  md <- meta[smp]
  if (shuffle) {
    idx <- seq_along(y)
    for (g in split(idx, md$colony)) if (length(g) > 1) idx[g] <- g[sample.int(length(g))]
    y <- y[idx]
  }
  X <- if (net_time) model.matrix(~ colony + st, md) else model.matrix(~ colony, md)
  E <- resid_rows(expr[[s]][orth[[s]], smp], X)
  yr <- resid_rows(matrix(y, 1), X)[1, ]
  as.vector(E %*% yr) / sqrt(rowSums(E^2) * sum(yr^2))
}
pairs <- list(c("Apul", "Peve"), c("Apul", "Ptua"), c("Peve", "Ptua"))
conc <- rbindlist(lapply(names(traits), function(tr)
  rbindlist(lapply(c(FALSE, TRUE), function(nt) {
    r <- lapply(setNames(names(sp), names(sp)), gene_trait_r, tr = tr, net_time = nt)
    rbindlist(lapply(pairs, function(pr) {
      obs <- stats::cor(r[[pr[1]]], r[[pr[2]]], method = "spearman")
      null <- vapply(seq_len(n_perm), function(b)
        stats::cor(r[[pr[1]]], gene_trait_r(pr[2], tr, nt, shuffle = TRUE),
                   method = "spearman"), numeric(1))
      data.table(trait = traits[[tr]], model = if (nt) "net of shared time" else "within colony",
                 pair = paste(pr, collapse = "-"), concordance = obs,
                 null_sd = sd(null), perm_p = (1 + sum(abs(null) >= abs(obs))) / (n_perm + 1))
    }))
  }))))
conc[, fdr := p.adjust(perm_p, "BH"), by = model]
fwrite(conc, file.path(out_dir, "ortholog-concordance.csv"))
